# SIKA 2 - Sistem Informasi Akademik

Proyek praktikum Aplikasi Berbasis Platform (Bab 2-4): HTML5 semantik, CSS3 responsif (Flexbox, Grid, media query), dan JavaScript (DOM, event, validasi form, pencarian tabel).

## Struktur
```
sika2/
|-- index.html            Dashboard
|-- mahasiswa.html        Profil + daftar mahasiswa (cari/filter)
|-- form-mahasiswa.html   Form dengan validasi
|-- assets/css/style.css
|-- assets/js/app.js
|-- assets/images/mahasiswa.svg
`-- docs/                 Artefak SDLC (01-requirements ... 04-testing)
```

## Menjalankan
Buka `index.html` di browser. Tidak perlu server atau instalasi.

## Catatan keamanan
Data adalah dummy. Tidak ada secret di client-side. Validasi JavaScript/HTML5 hanya untuk UX; validasi dan authorization akan dilakukan di server (PHP) pada Bab 6.
